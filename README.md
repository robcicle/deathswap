# DeathSwap Plugin

DeathSwap is a Minecraft plugin for Paper 1.21.4 that allows players to engage in a game where they swap locations at random intervals. The goal is to force your enemy into a near-death situation, survive and outlast your opponent for the win.

## Features

- Swap locations between two players at random intervals.
- Customizable countdown timer for swaps.
- Broadcast messages to all players about the game status.
- Fireworks display for the winner.

## Links

- [Spigot](https://www.spigotmc.org/resources/deathswap.81117/) - Build that supports 1.15 - 1.16.1 along with Spigot servers.

## Commands

- `/swap <Player1> <Player2> <CountdownTime>`: Starts the DeathSwap game between two players with a specified countdown time in minutes.
- `/stopswap`: Stops the ongoing DeathSwap game.

## Installation

1. Download the latest release of the plugin.
2. Place the plugin JAR file into the `plugins` folder of your Paper server.
3. Start or restart your server to load the plugin.
